## 🚀 Start Testing

### Option 1: Swagger UI
```bash
# 1. Open Browser
open http://localhost:8080/swagger-ui.html

# 2. Expand: /api/v1/jobs
# 3. Test endpoints in order:
#    - POST /batch-analyze
#    - GET /batch-progress-stream
#    - DELETE /batch-progress
```

### Option 2: Command Line
```bash
# Start Batch
curl -X POST http://localhost:8080/api/v1/jobs/batch-analyze

# Stream progress (another terminal)
curl -N http://localhost:8080/api/v1/jobs/batch-progress-stream

# Stop (another terminal)
curl -X DELETE http://localhost:8080/api/v1/jobs/batch-progress
```

### Option 3: Interactive Demo
```bash
# Open: kotlin-api/batch-progress-demo.html
# Or: python3 -m http.server 8001 -d kotlin-api/
#     → http://localhost:8001/batch-progress-demo.html
```
